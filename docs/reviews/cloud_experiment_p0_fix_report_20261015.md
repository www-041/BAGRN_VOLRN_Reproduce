## 实施内容

- 统一评分CLI默认使用分块/有界内存的streaming引擎，保留显式array参考引擎；支持按A/B1/B2/B3选择、scratch路径和RAM/磁盘预算。资源预检失败时拒绝生成评分报告。
- Streaming预检检查实际scratch卷；B1/B2单独评分不需要读取Mosaic；部分B2窗口保留记录并以null表示不可评分，不进入有效分母；单源区结构指标参照冻结RAW输入。
- 新增HARD来源标签逐块像元溯源审计；SOFT来源不冒充逐像元可验证来源。
- 新增按实验域区分的排名门：诊断结果资格与正式13景排名资格独立；严格核验样本规模、A/B1/B2完整度、资源来源、科学状态和HARD provenance。PAIR_ONLY诊断不能进入正式主榜。
- 新增跨主机冻结锁路径映射与逐文件SHA验证；锁文件保持只读。示例配置不含数据路径或密钥。
- 新增RAW方法产品准备/校验入口，不制造缺失影像或identity结果；PAIR_ONLY LIRRN与未验证LSSTAA保持非正式状态。
- BAGRN/VOLRN及Task16运行状态显式区分收敛、有限未收敛、无有效块对、数值无效、资源停止和失败；失败状态以非零退出码返回，同时保留诊断。
- RAW运行资源报告在成功或异常退出时均写出RSS、scratch和失败策略信息。
- 资源监控测试不再依赖脆弱的固定512 MiB阈值；仍核验实际采样、进程状态和非硬限制语义。

冻结公式、冻结掩膜/窗口、历史输出、算法核心公式与冻结文件均未修改。
