# Registration Pipeline Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved registration reliability design so BAGRN/VOLRN receives only a final, independently validated registration result.

**Architecture:** Keep `MultibandPipeline.register_scenes()` as the orchestration boundary and keep numerical operations in small helpers in `src/coregistration.py`. Pair measurements, refinement history, local-field decisions, independent validation, and final quality are explicit dictionaries; the final arrays are always generated by one warp from ORIGINAL arrays.

**Tech Stack:** Python, NumPy, SciPy, rasterio, pytest, YAML configuration, existing project helpers.

**Spec:** `docs/superpowers/specs/2026-09-08-registration-pipeline-design.md`

## Global Constraints

- Use Python first, not C++.
- Do not modify BAGRN or VOLRN mathematical formulas.
- Do not use pre-warp pair-shift consistency as the final registration quality result.
- Use one joint XY inlier mask for robust pair filtering.
- Use configured registration thresholds; do not add new hard-coded quality thresholds in orchestration.
- Generate every temporary and final registered image from the ORIGINAL array.
- Treat `nodata=None` as “no nodata value”; finite zero pixels remain valid.
- Apply local RBF only after control sufficiency, spatial coverage, and held-out CV gates pass.
- Preserve the existing graph fields in the registration result for compatibility.
- Preserve unrelated user changes, including the untracked `data/report_figures` output directory.
- Run each task's focused test after the implementation and commit that task before continuing.

## File Map

- `src/coregistration.py`: robust pair statistics, global residual refinement, local-control/RBF corrections, displacement warping, independent validation, and diagnostic statistics.
- `src/multiband_pipeline.py`: registration orchestration, local/refinement integration, final validation, stable result schema, and quality gate.
- `scripts/diagnose_registration_pair.py`: registration-only CLI, JSON serialization, and visual diagnostic artifacts.
- `docs/REGISTRATION_QUALITY_GATE.md`: document the actual final-registration flow and thresholds.
- `tests/test_registration_refinement.py`: focused red-green tests for new registration behavior.
- `tests/test_diagnostics_regressions.py` or a new diagnostic regression file: diagnostic schema/output contract.
